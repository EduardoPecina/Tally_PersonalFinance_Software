# _Programa

Carpeta administrada por el instalador (`INSTALAR.bat`). En una instalación,
aquí se copia el código de la aplicación y se reemplaza completa en cada
actualización.

- **No** es el lugar del código fuente: ese vive en `motor/` y `portal/`.
- **Nunca** contiene datos financieros: esos viven en la carpeta `Datos/` de
  la instalación, que las actualizaciones no tocan.
